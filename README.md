📚 Palabra Precisa - Plataforma Educativa de Lenguaje
Python Flask Bootstrap SQLite

Plataforma educativa interactiva para aprender y practicar el uso preciso del lenguaje, con énfasis en terminología técnica, prefijos, verbos, gentilicios y más.

🚀 Características
📊 Ejercicios Interactivos
100+ ejercicios de opción múltiple, completar espacios y corrección
Divididos en categorías: Prefijos, Frecuencia, Gentilicios, Verbos, Sustantivos, Gramática, Ciencia y más
Sistema de puntuación con niveles (Principiante a Experto)
Retroalimentación inmediata con explicaciones detalladas
🎴 Flashcards Interactivas
100 flashcards divididas en 5 niveles de dificultad
Interfaz interactiva con volteo de tarjetas
Sistema de pistas para ayudar en respuestas difíciles
Seguimiento de progreso por nivel
Bonificaciones por rachas de respuestas correctas
👤 Sistema de Usuarios
Registro e inicio de sesión seguro
Perfil personal con estadísticas de progreso
Ranking de usuarios por puntuación
Historial de intentos y ejercicios completados
📈 Seguimiento de Progreso
Puntuación total acumulada
Rachas actuales y mejores marcas
Nivel de experiencia (1-5)
Estadísticas por categoría y nivel
Visualización de progreso con gráficos
🛠️ Tecnologías Utilizadas
Backend: Flask (Python)
Base de Datos: SQLite con SQLAlchemy ORM
Frontend: Bootstrap 5, HTML5, CSS3, JavaScript
Autenticación: Flask-Login
Formularios: Flask-WTF
API: RESTful endpoints para verificación en tiempo real
